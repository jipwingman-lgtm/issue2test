# Contributing to Issue2Test

Thanks for contributing.

## Good first contributions

- Add reproducible examples from open-source Python projects.
- Improve prompt constraints that reduce hallucinated APIs.
- Add tests for CLI behavior.
- Improve support for larger repositories.

## Pull requests

1. Keep changes focused.
2. Add or update tests when behavior changes.
3. Run pytest before opening a pull request.
4. Never include API keys, private repositories, or confidential code.

## Bug reports

Please include the smallest source example and bug description that reproduces the problem.
